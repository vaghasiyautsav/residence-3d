# Vaghasiya Residence – 3D model

Interactive 3D model of the Vaghasiya Residence, 20 Telowie Avenue, Ingle Farm SA (Studio Forthwall project 26002).

**Live site:** https://upplushealth.github.io/vaghasiya-residence-3d/

The page is PIN protected. Ask the owner for the PIN.

## What you can do
- Orbit the exterior, or switch to the ground floor and first floor plan cut-aways
- Walk through the house in first person and open or close the doors
- Change the time of day, weather and lights
- Choose the flooring (timber or tiles) and the tapware finish
- Show the electrical estimate: downlights, power points, data and TV points, and the NBN connection
- Measure distances

Works in any modern browser on desktop or mobile. It is a single file (`index.html`) with no build step.
